# Deep Belief Networks

## Definition
The text describes Deep Belief Networks as "Bayesian networks that have multiple layers of hidden variables." This multi-layered structure allows them to capture complex, hierarchical patterns in data, which is a significant challenge in machine learning.

## Application in Learning
These networks are presented as a promising approach to one of the key problems in machine learning: "constructing new representations at levels of abstraction higher than the input vocabulary." For example, in computer vision, a deep belief network could learn to form intermediate concepts like *Desk* or *Tray* from raw pixel data, without explicit human supervision, which in turn helps in recognizing a higher-level concept like *Classroom*.

## Role in Agent Design
Deep Belief Networks can enable an agent to build up a library of high-level actions from simpler ones. The text gives the example of learning a complex behavior like *HavingACupOfTea* from an initial set of primitive actions like *RaiseArm* and *Swallow*. This ability to create abstractions is crucial for developing more capable and flexible intelligent agents.
