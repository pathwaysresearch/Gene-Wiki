# Data Engineering

## Role and Function
Data engineering is a labor-intensive activity focused on wrangling data to make it usable for AI applications. The primary role of data engineers is to build high-quality, high-volume data environments that make it possible for AI and data science teams to work effectively and efficiently.

## Team Integration
In many modern companies, data engineers are now included as core members of AI teams. This integration recognizes that preparing and managing data is a critical and specialized part of the AI development lifecycle, and that wrangling data is still a labor-intensive activity despite some help from AI tools.

## Supporting Technologies
Data engineers work with new systems that often use AI to manage data itself. These systems can perform tasks like probabilistic matching to combine data about the same entity from different databases, assist in data preparation by identifying quality problems, and create automated data catalogs to help users find the data they need.
