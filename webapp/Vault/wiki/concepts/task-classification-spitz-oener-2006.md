# Task Classification (Spitz-Oener, 2006)

## Definition

The Task Classification is a framework, notably used by Spitz-Oener (2006), for aggregating detailed work activities into five broader categories. This allows for a structured analysis of how the task content of jobs changes over time and in response to technological advancements.

## Task Categories

The framework distinguishes between five types of tasks. These are: (i) analytical non-routine tasks, which involve complex problem-solving; (ii) interactive non-routine tasks, which require interpersonal skills; (iii) cognitive routine tasks, which are procedural and rule-based; (iv) manual routine tasks, involving repetitive physical actions; and (v) manual non-routine tasks, which require physical adaptability.

## Application in the Study

The paper applies this classification to the German Qualifications and Career Surveys (BIBB-BAuA) data by generating these five task measures from 18 different task indicators. This allows for a comparison with similar measures from the BERUFENET expert database, which showed a relatively high correlation and provided an indication for task similarity between the two data sources.
