# Regression

## Definition
Regression is a type of learning problem where the goal is to predict a numerical output, y, based on an input, x. The output variable is a continuous number, not a category from a finite set.

## Example
An example of a regression problem provided in the text is predicting a specific numerical value, such as tomorrow's temperature. The model learns a function that maps input features to a continuous output.

## Contrast with Classification
Regression is distinct from classification, where the goal is to assign an input to one of a finite set of categories (e.g., *sunny*, *cloudy*, *rainy*). The key difference lies in the nature of the output variable: continuous for regression and discrete for classification.
