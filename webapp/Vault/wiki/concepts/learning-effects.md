# Learning Effects

## Definition
Learning effects capture the value that is added by increasing the amount of data flowing through a network. This data can be used to power artificial intelligence systems that learn from it, leading to improvements in the user experience, better targeting for advertisers, or other service enhancements. Generally, the more data that flows through the system, the better the service becomes.

## Distinction from Network Effects
Learning effects are distinct from network effects. While network effects relate to the value from the *number of connections* in a network, learning effects relate to the value from the *volume of data* that passes through it. For example, data from a network can be used to power AI to learn about and improve the user experience.

## Market Implications
Similar to network effects, strong learning effects can create a powerful competitive advantage and lead to increasing returns. As a service gathers more data, its AI can become smarter, making the service more attractive, which in turn attracts more users and generates even more data. This virtuous cycle can result in a market that tips toward a single dominant provider.
