# Unsupervised Clustering

## Definition
Unsupervised clustering is the task of discerning multiple categories in a collection of objects. The problem is defined as "unsupervised" because the category labels for the objects are not given, and the algorithm must discover these groupings from the data itself.

## Examples and Applications
A key application is in astronomy, where astronomers analyze the spectra of thousands of stars to identify different types, such as "red giants" and "white dwarfs," without prior labels. Other examples cited include the creation of the Linnæan taxonomy for biological species and the formation of natural kinds for ordinary objects.

## Methodological Approach
The process begins with a dataset, such as points with continuous attributes. The core assumption in clustering is that the data is generated from a mixture distribution. This distribution is composed of several components, where each component represents a distinct category or cluster. A data point is assumed to be generated by first selecting a component and then sampling from that component's own distribution.
