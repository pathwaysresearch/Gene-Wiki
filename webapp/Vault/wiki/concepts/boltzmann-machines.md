# Boltzmann Machines

## Overview
Boltzmann machines were introduced as a general 'connectionist' approach for learning arbitrary probability distributions over binary vectors. They are a foundational type of deep generative model, representing probability distributions over multiple variables.

## Model Family
While the original Boltzmann machine was defined for binary variables, the text notes that variants of the model that incorporate other kinds of variables have since surpassed the original in popularity. These models are structured probabilistic models that can be described using the language of graphical models.

## Learning Process
The learning process for Boltzmann machines involves a 'negative phase'. The text speculates, by referencing an earlier chapter, that dream sleep in animals and humans may be a biological implementation of the negative phase sampling required by these training algorithms, though this idea is noted as speculative.
