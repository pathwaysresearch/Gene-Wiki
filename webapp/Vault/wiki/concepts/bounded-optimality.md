# Bounded Optimality

## Definition
The text defines a bounded optimal agent as one that "behaves as well as possible, given its computational resources." This means the expected utility of the agent's program is at least as high as that of any other agent program that could be run on the same machine or with the same computational constraints.

## A Foundation for AI
Bounded optimality is presented as offering the "best hope for a strong theoretical foundation for AI." Unlike the ideal of perfect rationality, which is often unachievable, bounded optimality is always possible because there is, by definition, at least one best program for a given set of resources.

## Practicality and Usefulness
This concept is highly practical because it directly incorporates the real-world constraints of the agent's hardware. It provides a formal framework for designing agents that make the best possible use of their limited computational budget, making them useful in real-world applications where resources are finite.
