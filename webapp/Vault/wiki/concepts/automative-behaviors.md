# Automative Behaviors

## Definition
Automative Behaviors represent a mode of integrating AI into a workflow where the AI is tasked with directly executing tasks with minimal human involvement. This approach contrasts with more collaborative, augmentative uses of AI.

## Interaction Patterns
Handa et al. (2025) identify two distinct patterns within this category based on their analysis of conversations with the LLM Claude. The first is **Directive** behavior, which involves complete task delegation with minimal interaction, such as a user commanding the AI to "Format this technical documentation in Markdown." The second pattern is the **Feedback Loop**, where task completion is guided by environmental feedback. An example of this is a user providing a Python script, receiving an error, and asking the AI for help fixing it, potentially in an iterative cycle of errors and fixes.

## Context of Study
This concept is part of a classification framework developed by Handa et al. (2025) to categorize how people use LLMs. The framework was derived from analyzing conversations with the AI model Claude and provides a structured way to understand different modes of AI-human workflow integration.
