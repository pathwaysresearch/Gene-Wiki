# Noncollapsibility

## Definition
Noncollapsibility is a procedural definition used to identify confounders, as described in a 1996 paper by Sven Hernberg. It is based on a statistical test performed directly on data, appealing to statisticians who prefer not to rely on a causal model.

## How It Works
According to this definition, a variable is tested as a potential confounder by comparing a crude measure of association (e.g., relative risk) with an adjusted measure that accounts for the variable. If there is a difference between the crude and adjusted estimates, the variable is deemed a confounder, and the adjusted estimate is used. If there is no significant difference, confounding is considered not to be an issue.

## Limitations
This approach is considered misguided because it relies purely on statistical associations without reference to an underlying causal model. It has been criticized for having misled a century of researchers in epidemiology, economics, and social sciences. The method can fail to identify true confounders or incorrectly flag non-confounders, depending on the causal structure of the problem.
