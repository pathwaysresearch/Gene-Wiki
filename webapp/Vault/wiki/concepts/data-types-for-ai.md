# Data Types for AI (Training, Input, Feedback)

## Definition of Types
The text identifies three distinct types of data for prediction machines. **Training data** is historical data used at the beginning to build and train an algorithm. **Input data** is the new data fed into a trained model to generate a specific prediction in real-time. **Feedback data** is information on the accuracy of past predictions, which is used to improve and retrain the machine over time.

## Strategic Value and Sustainability
The strategic value of these data types differs significantly, challenging the simple notion that all data is a sustainable asset like oil. Training data has limited sustained value; once it has been used to train a model, its utility is largely exhausted, as if it has been "burned." In contrast, input and feedback data are crucial for the ongoing operation and improvement of the prediction machine. A sustained competitive advantage is more likely to come from a continuous flow of new input and feedback data rather than a static repository of historical training data.

## Implications for Competitive Advantage
A company's repository of past data, such as historical yogurt sales, may be valuable for building an initial prediction machine, but it is unlikely to be a source of *sustained* value. To maintain an advantage, a business needs a mechanism to continuously generate new input data to power predictions and feedback data to refine them. This shifts the strategic focus from simply possessing a large dataset to creating business processes that generate valuable, ongoing data flows.
