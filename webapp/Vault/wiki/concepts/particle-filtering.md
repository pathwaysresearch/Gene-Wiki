# Particle Filtering

## How It Works
Particle filtering is an algorithm that uses a set of N samples to approximate the current state distribution in a Dynamic Bayesian Network (DBN). Instead of processing samples individually, the algorithm runs all N samples together through the DBN, one time slice at a time, treating the set of samples as the forward message. The update cycle involves three main steps. First, each sample is propagated forward by sampling the next state based on the transition model. Second, when an observation is made, each sample is weighted by its likelihood for that observation. Third, a new set of N samples is generated by performing weighted random selection from the current weighted set, a process also known as resampling.

## Historical Development and Variants
The algorithm has a varied history, having been independently developed in several fields under different names. It was first developed in control theory by Handschin and Mayne (1969), with the core resampling idea appearing in a Russian journal (Zaritskii et al., 1975). It was later reinvented as 'sequential importance-sampling resampling' (SIR) in statistics, 'particle filtering' in control theory (Gordon et al., 1993), 'survival of the fittest' in AI (Kanazawa et al., 1995), and 'condensation' in computer vision (Isard and Blake, 1996). An important improvement is 'evidence reversal,' where the state at time t+1 is sampled conditioned on both the state at t and the evidence at t+1, allowing evidence to directly influence sample generation. A notable variant is the Rao-Blackwellized particle filter (RBPF).

## Applications and Properties
Particle filtering is a consistent algorithm, meaning it provides the correct probabilities as the number of samples N approaches infinity. A key advantage is that it requires a constant amount of time and space per update, as it only needs to keep the current and next time slices in memory. The method has been applied to a wide range of problems, including tracking complex motion patterns in video, predicting the stock market, and diagnosing faults on planetary rovers.
