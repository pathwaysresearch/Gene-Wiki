# Anomaly Detection

## Definition

Anomaly detection is a type of unsupervised learning algorithm that identifies outliers in a dataset. The algorithm examines each new incoming observation or datum and makes a judgment on whether it fits with prior, established patterns.

## How It Works

The core mechanism involves pattern recognition. If a new piece of data does not fit the existing pattern that the algorithm has learned from previous data, the algorithm flags that item as anomalous.

## Purpose

The primary function of anomaly detection is to identify unusual events, errors, or rare items in a dataset. This is critical for applications like fraud detection, system health monitoring, and identifying novel scientific discoveries.
