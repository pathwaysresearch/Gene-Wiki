# Maximum Likelihood Estimation

## Principle
Maximum Likelihood Estimation (MLE) is presented as a foundational principle for deriving specific functions that are good estimators for different models, rather than relying on guesswork. The core idea is to view the observed data as having been generated by a parametric family of probability distributions, p_model(x; θ). The MLE principle then selects the parameter values θ_ML that maximize the probability of observing the given dataset X.

## Formulation
For a set of m independent and identically distributed (i.i.d.) examples X = {x^(1), ..., x^(m)}, the likelihood of the data is the product of the probabilities of each individual example: p_model(X; θ) = ∏ p_model(x^(i); θ). The maximum likelihood estimator is the value of θ that maximizes this product. For numerical stability and mathematical convenience, this is often implemented by maximizing the sum of the log-probabilities, as the argmax is unchanged by the monotonic logarithm function.

## Application to Linear Regression
The text demonstrates that the common practice of minimizing mean squared error (MSE) for linear regression can be justified as a maximum likelihood procedure. If we model the output y as being drawn from a Gaussian distribution conditioned on the input x, p(y | x) = N(y; ŷ(x; w), σ²), where ŷ(x; w) is the linear model's prediction. Maximizing the log-likelihood of the data under this model is equivalent to minimizing the MSE between the predictions ŷ and the true target values y.
