# Expert System

## Definition and Methodology
An expert system is a knowledge-intensive system whose expertise derives from a large number of special-purpose rules. A key methodological principle, pioneered by systems like DENDRAL, is the clean separation of the knowledge base (the rules) from the reasoning component.

## Historical Development
Following the success of DENDRAL, the Heuristic Programming Project (HPP) at Stanford, involving researchers like Feigenbaum, was initiated to explore the application of the expert system methodology to other areas of human expertise.

## Key Examples
DENDRAL was the first successful knowledge-intensive system, using rules for spectrum prediction. Another major effort was MYCIN, a system for diagnosing blood infections, which used around 450 rules acquired from human experts to perform at a level comparable to specialists.
