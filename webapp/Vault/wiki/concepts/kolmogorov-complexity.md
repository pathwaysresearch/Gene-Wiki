# Kolmogorov Complexity

## Definition
Kolmogorov complexity, also referred to as algorithmic complexity, provides a formal definition for the concept of simplicity. It quantifies the complexity of an object as the length of the shortest computer program that can generate that object as its output.

## Origin
The theory was developed independently by two researchers: Ray Solomonoff in 1964 and Andrey Kolmogorov in 1965.

## Purpose in Learning Theory
This concept was developed to formalize the notion of simplicity used in principles like Ockham's razor. In contrast to other learning theory approaches like 'identification in the limit' that focus on eventual convergence, Kolmogorov complexity provides a framework for analyzing the inherent complexity of data and models.
