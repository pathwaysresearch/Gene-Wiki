# Task-Based Model

## Definition

A task-based model is an economic framework where the production of a final good is conceptualized as the combination of a set of distinct tasks. The model presented in the text uses a production function where the outputs of individual tasks, denoted y(z), are combined to create total output Y, with an elasticity of substitution σ between them. This structure allows for a granular analysis of how technological changes, like AI, affect the economy by altering how specific tasks are performed.

## Core Components

In this framework, tasks can be produced using different factors of production, primarily capital and labor, each with its own task-specific productivity schedule. A key feature is the allocation of tasks between these factors. The model often defines a threshold, I, which separates tasks automated and performed by capital from those still performed by labor. Changes in technology, such as AI, can shift this threshold, reallocating tasks from labor to capital in a process known as automation.

## Application to AI Economics

This model is the central analytical tool used in the paper to evaluate the macroeconomic implications of AI. AI's effects are analyzed through two primary channels: automation, where AI systems take over tasks previously performed by humans, and task complementarities, where AI tools enhance the productivity of human workers in the tasks they continue to perform. By modeling these distinct effects, the framework can be used to predict AI's impact on GDP, productivity, wages, and inequality.
