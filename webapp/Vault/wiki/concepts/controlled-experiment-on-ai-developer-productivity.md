# Controlled Experiment on AI Developer Productivity

## Definition
The study employed a controlled experiment to isolate and measure the effect of an AI pair programmer, GitHub Copilot, on the productivity of software developers. Recruited participants were divided into a treatment group, which had access to Copilot, and a control group, which did not, to establish a causal link between the tool and performance outcomes.

## Experimental Design
The experiment tasked software developers with a specific coding challenge: to implement an HTTP server in JavaScript as quickly as possible. The entire process was managed using GitHub Classroom, which provided participants with a template repository and a standardized test suite containing twelve checks for correctness. The primary metric for success was the time taken to complete the task.

## Key Findings
The results of the experiment demonstrated a significant productivity increase attributable to the AI tool. The treatment group, which used GitHub Copilot, completed the coding task 55.8% faster on average than the control group. The study also gathered subjective data through an exit survey, which measured participants' self-reported productivity gains and their willingness to pay for the tool, providing a multi-faceted view of the AI's impact.
