# Direct Network Effects

## Definition
Direct network effects are a form of network effect where users directly value the presence of other users within the same category. The value for any given user is a direct function of the total number of participants on the network.

## How It Works
In a system with direct network effects, each new user adds value to all existing users. The classic example is the fax machine; the first one was useless, but its value grew as more people and businesses acquired them, expanding the network of potential communication partners.

## Examples
The text cites several examples of products and services that exhibit direct network effects. These include fax machines, messaging applications, and social networks, all of which become more useful to an individual as more of their contacts or the general public join the platform.
