# Path Analysis

## Definition and Purpose
Path analysis is a method created by Sewall Wright to bridge the gap between rung one (association) and rung two (causation) of the Ladder of Causation. It is centered on the use of a path diagram, which the text calls a "scientific revolution in one picture." This diagram serves as a visual map of all conceivable causal factors and their hypothesized relationships, such as the developmental, environmental, and hereditary factors affecting a guinea pig's pigmentation.

## How It Works
The method involves first postulating a set of causal relationships in a path diagram. Wright then developed a mathematical technique using "path coefficients" to quantify the strength of these causal links. His method allows one to express the measured correlations between variables as algebraic functions of the unknown path coefficients. By creating a system of equations from the observed correlations, one can solve for the path coefficients, thereby calculating the strength of a direct causal link. For instance, Wright used it to calculate that a one-day increase in gestation time would cause a 3.34-gram increase in a guinea pig's birth weight, holding other factors constant.

## Core Principles and Application
A fundamental principle articulated by Sewall Wright is that one cannot draw causal conclusions without first making some causal hypotheses, which are encoded in the path diagram. This counters the criticism that the reasoning is circular. The method can also be used in an exploratory mode: if the correlations predicted by the diagram and its calculated coefficients contradict the actual data, then the assumed causal relationships can be considered falsified. This way of using path diagrams was later rediscovered by Herbert Simon and influenced much work in the social sciences.
