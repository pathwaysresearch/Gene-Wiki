# Term (First-Order Logic)

## Definition
In the context of first-order logic, a term is a logical expression that refers to an object. It is a fundamental syntactic construct used to name or identify objects within the domain of discourse.

## Forms of Terms
Terms can take several forms. A constant symbol is a term that names a specific object. A more complex term can be constructed from a function symbol applied to one or more argument terms, as in the example "King John's left leg." A variable, denoted by a lowercase letter, is also considered a term by itself.

## Ground Terms
A term that contains no variables is referred to as a ground term. These terms always refer to a specific, fixed object within a given interpretation, as opposed to terms with variables, which can refer to different objects depending on the variable's assignment.
