# Contextual Value of Tasks

## Definition
A task's contextual value is its importance and relevance within a specific organizational or systemic context. This is distinct from its intrinsic value (the inherent difficulty or creativity of the task) and its direct economic value. The text emphasizes that as AI changes the broader system, a task's contextual value can shift dramatically even if its intrinsic nature remains the same.

## Relationship to System Constraints
Contextual value is directly linked to the new constraints that emerge in a system transformed by technology. When a skill like coding becomes commoditized by AI, the primary constraint is no longer the ability to write code but rather the ability to validate it and integrate it into a larger, logical software system. The tasks associated with this new constraint, therefore, acquire high contextual value, as they become the new bottleneck for progress.

## Implications for Workers
Individuals are advised to evaluate their jobs based on contextual value rather than just the intrinsic difficulty of their skills. As AI makes certain knowledge and skills widely accessible, the value shifts. For example, a professor's role, once centered on knowledge transfer, now finds higher contextual value in providing motivation and inspiration, because the knowledge itself is easily accessible via AI. To remain relevant, workers must identify and move toward the new constraints where contextual value is highest.
