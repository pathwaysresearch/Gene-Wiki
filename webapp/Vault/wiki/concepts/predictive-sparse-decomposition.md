# Predictive Sparse Decomposition

## Overview
Predictive Sparse Decomposition (PSD) is a model that integrates principles from both sparse coding and parametric autoencoders. It is composed of a parametric encoder, denoted `f(x)`, and a parametric decoder, `g(h)`. The training process involves an optimization procedure to find a sparse latent representation `h` for a given input `x`.

## Training Objective
The model is trained by minimizing a composite objective function with three main components. The first is a reconstruction error term, `||x - g(h)||^2`, which ensures the decoder can reconstruct the input from the latent code. The second is an L1 sparsity penalty, `λ||h||_1`, which encourages the latent code `h` to be sparse. The third term, `γ||h - f(x)||^2`, forces the output of the parametric encoder `f(x)` to match the optimized sparse code `h`.

## Applications
PSD has been effectively used for unsupervised feature learning across several domains. Its applications include object recognition in both static images and video sequences, as well as feature extraction for audio processing tasks.
