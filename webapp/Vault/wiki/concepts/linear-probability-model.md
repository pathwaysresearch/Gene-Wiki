# Linear Probability Model

## Definition
A Linear Probability Model (LPM) is a type of regression model where the dependent variable is a binary or dummy variable, representing an outcome like yes/no or true/false. The model estimates the probability of the outcome occurring based on a set of independent variables, as shown in the analysis where the dependent variable is a "Dummy for being employed in new work".

## Application in Analysis
The provided text applies Linear Probability Models to analyze the factors influencing employment in new types of work. The models assess how the probability of being employed in new work is affected by independent variables such as worker earnings and different levels of education. The results are presented in a table showing the estimated coefficients for these variables.

## Methodological Considerations
The analysis using this model incorporates several important methodological controls to ensure the validity of the results. The models include occupation fixed effects ("Occupation FE") and a set of 'Full Controls' for age, sex, race, and state. Furthermore, the text specifies the use of robust standard errors, a common practice with LPMs to correct for potential statistical issues like heteroscedasticity.
