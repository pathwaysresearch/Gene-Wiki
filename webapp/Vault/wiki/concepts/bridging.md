# Bridging (in networks)

## Definition
Bridging is a business strategy where a firm connects multiple networks, often with different types of participants and value propositions, to improve its ability to both create and capture value. By linking these networks, the firm can build important synergies and leverage assets, such as a user base or data, across different markets.

## How It Works
A firm that has achieved critical mass with a user base on one network can use this asset to enter and monetize a different network. Data-based assets are particularly useful for bridging because they are often applicable across many scenarios. This strategy is fundamental to the expansion of hub firms like Amazon and Alibaba into diverse markets.

## Examples
Google provides a classic example by bridging its search network with an advertiser network, charging advertisers for access to users' search intent. Alibaba is another key example, having successfully bridged its e-commerce platforms (Taobao, TMall) with financial services by leveraging its payment network (Alipay) and user transaction data.
