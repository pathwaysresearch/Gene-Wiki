# Indirect Network Effects

## Definition
Indirect network effects occur on multisided platforms or networks where there are at least two distinct user groups. The value for users in one group increases as the number of users in the other, complementary group grows.

## How It Works
The platform's core function is to facilitate valuable interactions between these different user groups. For instance, on a ride-hailing platform, riders value a large number of available drivers because it reduces wait times, while drivers value a large number of riders because it increases their potential earnings and reduces idle time.

## Examples
The text cites Uber and Airbnb as prime examples of networks that exhibit indirect network effects. On Uber, riders value the presence of drivers, and vice versa. Similarly, on Airbnb, vacationers and renters value a large selection of available properties, while property owners value a large pool of potential renters.
