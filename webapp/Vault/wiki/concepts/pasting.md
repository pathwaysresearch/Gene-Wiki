# Pasting

## Definition
Pasting is an ensemble learning technique that involves training multiple predictors on various random subsets of the training data. Unlike bagging, the subsets in pasting are generated by sampling *without* replacement. This means that once an instance is selected for a subset, it cannot be selected again for that same subset.

## Comparison with Bagging
The primary difference between pasting and bagging lies in the sampling method. Bagging uses sampling with replacement (bootstrapping), while pasting uses sampling without replacement. Both methods allow for predictors to be trained in parallel, making them highly scalable.

## Implementation
In Scikit-Learn, pasting can be implemented using the `BaggingClassifier` or `BaggingRegressor` classes. To use pasting instead of the default bagging, the hyperparameter `bootstrap` must be set to `False`.
