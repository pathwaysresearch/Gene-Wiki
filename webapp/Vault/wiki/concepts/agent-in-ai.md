# Agent (in AI)

## Definition
An agent is defined as anything that can be viewed as perceiving its environment through sensors and acting upon that environment through actuators. This provides a unifying framework for studying AI.

## Interaction with Environment
An agent's interaction with its environment is characterized by its perceptions and actions. The term 'percept' refers to the agent's perceptual inputs at any given moment, and the 'percept sequence' is the complete history of everything the agent has ever perceived.

## Types of Agents
The concept of an agent is broad and applies to various systems. A human agent uses organs like eyes and ears as sensors and body parts like hands and legs as actuators. A robotic agent might use cameras and range finders as sensors and motors as actuators. A software agent receives inputs like keystrokes and network packets and acts by writing files or displaying on a screen.
