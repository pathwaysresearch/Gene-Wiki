# Stratified Sampling

## Definition
Stratified sampling is a technique used to create a representative sample from a population by first dividing the population into distinct subgroups, or strata, based on a shared characteristic. It ensures that when splitting data, for example into training and test sets, the proportions of key categories in a feature are maintained in the sample, thus avoiding sampling bias that can occur with purely random sampling.

## How It Works
To perform stratified sampling on a continuous numerical attribute like median income, the attribute must first be converted into a categorical attribute with a sufficient number of strata. For instance, the median income data was divided into income categories. Then, a tool like Scikit-Learn's `StratifiedShuffleSplit` class is used to generate indices for a test set, ensuring that the proportion of instances from each income category in the test set matches the proportion in the overall dataset.

## Importance and Comparison
The text demonstrates the value of stratified sampling by comparing the income category proportions in a test set it generated versus one generated by purely random sampling. The stratified test set had proportions almost identical to the full dataset, with very low error percentages. In contrast, the randomly sampled test set was significantly skewed, highlighting how stratified sampling is crucial for ensuring the test set accurately reflects the overall data distribution, especially for important predictive features.
