# Reusable Authoritative Data Set (RAD)

## Definition
The Reusable Authoritative Data Set (RAD) is a data delivery approach developed and implemented at Scotiabank. Its primary goal is to accelerate the provision of high-quality data for analytics and AI use cases by identifying and creating standardized, reusable data sets for core domains such as customer data, transactional data, and balance data.

## Strategic Shift
The introduction of the RAD approach marked a significant evolution in Scotiabank's data strategy. The bank's data management function had previously been focused primarily on a defensive, 'protect-the-bank' posture that emphasized regulatory compliance, financial reporting, and risk management. The RAD model added an offensive focus on enabling customer insights and achieving rapid value realization from data.

## Benefits and Impact
This approach is designed to enhance the speed, consistency, and value derived from data initiatives. By creating reusable assets, it allows for faster and more efficient development of AI models that depend on this data. According to Scotiabank's Chief Data Officer, Peter Serenita, the RAD approach has made it common for data projects at the bank to generate a high return on investment (ROI).
