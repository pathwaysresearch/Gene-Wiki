# Heuristic Function

## Definition
A heuristic function, commonly denoted $h(n)$, provides an estimate of the cost to reach a goal from a given state $n$. It is a core component of informed search algorithms, which leverage this domain-specific knowledge to search the state space more efficiently than uninformed methods. In local search, the heuristic function's value can be interpreted as the 'elevation' in a state-space landscape.

## Key Properties
Two critical properties for heuristics in algorithms like A* are admissibility and consistency. An admissible heuristic never overestimates the true cost to the goal. A consistent heuristic is a stricter condition which requires that for any node $n$ and any successor $n'$ generated by an action $a$, the estimated cost of reaching the goal from $n$ is no greater than the step cost of getting to $n'$ plus the estimated cost from $n'$. A consistent heuristic is always admissible.

## Derivation and Impact
Heuristics can often be derived from a relaxed version of the problem, where some constraints are removed. For example, Gaschnig's heuristic for the 8-puzzle is derived from the exact solution to a relaxed version of the puzzle. The choice of heuristic is crucial; an admissible heuristic guarantees optimality for A*, while one that overestimates can lead to suboptimal solutions.
