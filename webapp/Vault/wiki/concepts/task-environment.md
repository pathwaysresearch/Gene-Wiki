# Task Environment

## Definition
Task environments are described as the "problems" for which rational agents are the "solutions." They are the external setting in which an agent perceives, acts, and is evaluated. The complexity of a task environment is determined by the relationship between the agent's behavior, the percept sequence generated by the environment, and the performance measure.

## Dimensions of Classification
Task environments are classified along several key dimensions. One is the distinction between single-agent and multiagent environments. In a multiagent environment, the behavior of other entities is best described as maximizing a performance measure that depends on the primary agent's actions. These can be competitive, like chess, where one agent's gain is another's loss, or cooperative, like taxi driving, where avoiding collisions benefits all agents.

## Other Key Properties
Environments can also be classified as discrete or continuous, which applies to the state of the environment, the handling of time, and the agent's percepts and actions; chess is discrete, while taxi driving is continuous. Another critical distinction is between known and unknown environments. This refers to the agent's knowledge of the environment's "laws of physics." In a known environment, the outcomes of actions are given, whereas in an unknown one, the agent must learn how the world works to make good decisions. This is different from observability, as an environment can be known but only partially observable, like in solitaire card games.
