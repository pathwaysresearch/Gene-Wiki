# Granger Causality Test for Innovation

## Purpose in Context
The Granger causality test (Granger, 1969) is employed in this study to validate the measure of “breakthrough” innovations. Specifically, it tests whether current patenting activity in a given technology class predicts the emergence of future breakthrough patents (defined as top 10% cited) in that same class. The expectation is that true breakthroughs should not be predictable from current innovation flows.

## Methodology
The test is conducted by regressing contemporaneous patent flows by technology class in a given decade (t) on measures of future breakthroughs and non-breakthroughs (bottom 10%) that occur in the subsequent decade (t+10). This “reverse” causality check assesses if future outcomes predict current activity.

## Findings and Interpretation
The results of the test show that future breakthroughs do not positively predict current innovation activity; in fact, the relationship is negative. This supports the idea that breakthroughs often originate in technology classes with little ongoing activity. Conversely, future low-impact patents (bottom 10%) are strongly and positively correlated with current patenting levels, suggesting that active fields tend to produce many incremental, low-impact innovations.
