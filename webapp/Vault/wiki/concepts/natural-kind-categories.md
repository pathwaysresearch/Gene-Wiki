# Natural Kind Categories

## Definition
Unlike categories with strict definitions, such as a triangle being a polygon with three sides, most categories in the real world are *natural kind* categories which have no clear-cut definition. Instead of a set of necessary and sufficient conditions, they are characterized by a collection of typical features that objects in the category tend to have.

## Characteristics and Examples
The text uses the tomato as a primary example of a natural kind. A typical tomato is described as dull scarlet, roughly spherical, two to four inches in diameter, with a thin skin and specific internal structure. However, the category accommodates significant variation: some tomatoes are yellow or orange, some are much smaller (like cherry tomatoes), and unripe ones are green. This variation means that while we can identify typical members, the boundaries of the category are fuzzy.

## Implications for Logical Agents
The nature of these categories poses a significant problem for a logical agent operating in a partially observable environment. Because there is no strict definition, an agent cannot be absolutely sure that a perceived object is a member of a category (e.g., a tomato). Furthermore, even if membership is established, the agent cannot be certain which of the typical properties the specific object possesses, as any given feature might not be present in a particular instance.
