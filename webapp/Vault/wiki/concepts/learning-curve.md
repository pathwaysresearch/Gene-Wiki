# Learning Curve

## Definition
A learning curve is a tool for measuring the performance of a learning algorithm. It is a graph that shows the prediction accuracy of a model on the test set plotted as a function of the size of the training set.

## Purpose
By analyzing the shape of a learning curve, one can diagnose whether a model is benefiting from more data or if it suffers from issues like high bias (underfitting) or high variance (overfitting). It provides insight into the relationship between data quantity and model performance.
