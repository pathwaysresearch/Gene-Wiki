# Data (as a complement to prediction)

## Definition
Data is the raw information that a prediction machine uses as input to generate new, previously missing information. The book's definition of prediction explicitly states that it "takes information you have, often called ‘data,’ and uses it to generate information you don’t have."

## Economic Role
Data is identified as a key complement to prediction. According to the economic principle of complements, as AI makes prediction cheaper, the value of the data required to fuel those predictions rises. The book's structure emphasizes this by planning to delve into "the types of data required to make good predictions."

## Example of Value
The acquisition of Mobileye by Intel is used as a prime example of the increasing value of data. Mobileye's core value was its "data-collection technology that allows vehicles to effectively see," which provides the essential input for the prediction tasks performed by autonomous driving systems. This demonstrates the high market value placed on a key complement to prediction.
