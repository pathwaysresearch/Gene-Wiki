# Network Effects

## Definition
Network effects describe the value that is added by increasing the number of connections within and across networks. A service with network effects becomes more valuable to each user as the total number of users or connections grows. The text provides the example of Facebook, where the value for a user increases as more of their friends join the platform, or as more developer applications become available.

## Distinction from Learning Effects
Network effects are distinct from learning effects. While network effects are about the value derived from the *number of connections*, learning effects are about the value derived from the *amount of data* flowing through those connections, which can be used to power AI and improve the service. Though different, the two effects can be mutually reinforcing.

## Impact on Market Structure
The strength of network effects can determine market dynamics. As illustrated in the text, strong network and learning effects can lead to increasing returns, causing a market to "tip" toward a winner-take-all outcome. Conversely, weak network effects allow for a market where multiple competitors can coexist. The text also provides an example of a disease management app that creates value by connecting a network of stakeholders, including patients, physicians, insurers, and pharmacies.
