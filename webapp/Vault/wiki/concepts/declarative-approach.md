# Declarative Approach

## Definition
The declarative approach to building a system, such as a knowledge-based agent, involves populating a knowledge base with sentences that describe the environment and the desired behavior. The agent designer essentially TELLS the system what it needs to know, starting from an empty knowledge base, until it is competent enough to operate.

## Contrast with Procedural Approach
This method stands in contrast to the procedural approach, where desired behaviors are encoded directly as program code. The text notes that while historical debates existed between proponents of these two paradigms, a successful modern agent often incorporates both declarative and procedural elements in its design.

## Advantages and Implementation
A key benefit of the declarative approach is flexibility. An agent can be assigned new tasks through explicitly described goals and can adapt to environmental changes simply by updating its knowledge base. Furthermore, the text mentions that declarative knowledge can often be compiled into more efficient procedural code for execution, bridging the gap between the two approaches.
