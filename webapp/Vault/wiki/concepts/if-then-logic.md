# If-Then Logic

## Definition
All machines are programmed using the classic if-then logic. The "if" component specifies a particular scenario, environmental condition, or piece of information. The "then" component instructs the machine on the action to take for each of the specified "ifs," as well as for related conditions like "if nots" and "elses."

## Role in Machine Capability
The number of "ifs" a machine can distinguish and handle determines its operational complexity and the environments it can navigate. For example, an early mail robot was limited to controlled environments with few "ifs." In contrast, a modern Roomba can handle many more "ifs" (e.g., stairs, corners, room layout) using sensors and memory, allowing it to operate in uncontrolled, complex spaces.

## Impact of AI and Prediction
Enhanced prediction from AI liberates machines from the need to have every potential "if" explicitly coded in advance. Instead of programming for every possible situation on a city street, a prediction machine can be trained with examples of what a human controller would do. This allows autonomous vehicles to handle the vast number of "ifs" in uncontrolled environments, leading to better outcomes.
