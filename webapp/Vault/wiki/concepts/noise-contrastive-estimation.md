# Noise-Contrastive Estimation (NCE)

## Core Idea
Noise-Contrastive Estimation (NCE) circumvents the intractable partition function by transforming the problem of density estimation into a problem of learning a probabilistic binary classifier. The goal of the classifier is to distinguish samples from the true data distribution from samples generated by a known noise distribution.

## How It Works
NCE treats the log partition function, -log Z(θ), as an additional parameter, c, to be learned alongside the model's main parameters, θ. The model's log probability is then written as log p(x) = log p̃(x; θ) + c. The training objective is to maximize the likelihood of correctly classifying data samples as 'real' and noise samples as 'fake'. This supervised objective is constructed such that its maximum corresponds to the maximum likelihood estimate of the original unsupervised model.

## Properties
Unlike a naive maximum likelihood approach which would simply drive the parameter c to be arbitrarily high, the NCE objective forces c to be a reasonable estimate of -log Z(θ) to achieve good classification performance. While NCE has generated the most interest as a means of estimating models with difficult partition functions, it is also applicable to problems where the partition function is tractable.
