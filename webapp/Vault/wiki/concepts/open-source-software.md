# Open Source Software

## Definition and Licensing
Open source software is software made available for free and licensed under terms like the GNU Public License (GPL). The GPL guarantees that any product derivative of the free software will also be made available for free.

## Contributor Motivations
The open source approach has attracted the enthusiasm and imagination of millions of contributors who join forces to improve software globally. They are motivated by a variety of incentives, including skills development, explicit corporate assignments, intrinsic enjoyment, reputation building, and a sense of community and common cause.

## Prominent Examples and Impact
Open source software powers a huge variety of popular products and infrastructure. Examples include Linux, the most popular cloud operating system; web servers like Apache; browsers like Firefox; databases like MySQL; user interface libraries like REACT; and the machine learning framework TensorFlow. The approach has also been effective beyond software infrastructure, as seen with the online listing service Craigslist.
