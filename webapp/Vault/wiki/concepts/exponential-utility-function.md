# Exponential Utility Function

## Definition
The exponential utility function is a model used by economists to represent the utility of money. It is given by the formula $U(x) = -e^{-x/R}$, where $x$ is the monetary amount and $R$ is a positive constant representing an individual's risk tolerance.

## The Role of Risk Tolerance (R)
The parameter $R$, which is measured in the same units as $x$, quantifies an individual's attitude towards risk. It reflects how likely an individual is to accept a lottery with a certain expected monetary value (EMV) versus a guaranteed payoff. As the value of $R$ becomes larger, the individual becomes less risk-averse.

## Application in Decision Making
This function is used to model rational choices under uncertainty. To decide between a certain payoff and a lottery, an individual with this utility function would calculate the expected utility of each option. For the lottery, this involves weighting the utility of each possible outcome by its probability. The rational choice is the option with the higher expected utility, which may not be the one with the higher expected monetary value, thus explaining risk-averse behavior.
