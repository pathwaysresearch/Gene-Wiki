# Anatomy of a Task

## Definition
The Anatomy of a Task is a model for understanding the elements of a decision. As outlined in the text and an accompanying figure, a decision is not a single event but a process flow. This flow consists of several key components: input data, prediction, judgment, action, and outcome. The framework also includes a feedback loop where data from outcomes is used for training, which in turn improves future predictions.

## Core Components
The central components of this framework are prediction and judgment. Prediction is the process of using information you have to generate information you don't have; in the context of AI, this is the element that machines are increasingly able to perform better, faster, and cheaper than humans. Judgment is the process of determining the payoff or value associated with each possible outcome. An action is the choice made based on the prediction and judgment, which then leads to an outcome. The framework is dynamic, with feedback and data from outcomes being used to train the prediction model.

## Economic Implications
This framework is crucial for understanding the economic impact of prediction machines. By breaking a decision down, it becomes clear that AI-driven prediction is a substitute for human prediction, causing the value of the latter to decline. This was seen with London cabbies, whose predictive skill ("The Knowledge") was devalued by navigation apps. Conversely, the value of complements to prediction—such as data collection, judgment, and the ability to take actions—increases as prediction becomes cheaper and more abundant.
