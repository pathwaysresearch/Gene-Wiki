# Answer Set Programming

## Definition and Origins
Answer set programming (ASP) is a form of declarative programming based on the stable model semantics. The text describes it as being viewable as either an extension of the negation-as-failure concept from logic programming or as a refinement of the nonmonotonic formalism of circumscription. The underlying theory of stable model semantics was introduced by Gelfond and Lifschitz in 1988.

## Prominent Systems
The text identifies two leading answer set programming systems. One is DLV, developed by Eiter et al. in 1998. The other is SMODELS, developed by Niemelä et al. in 2000, whose user manual provided the disk drive example mentioned in the chapter.

## Applications
The utility of answer set programming extends to various AI problems. The text specifically cites Vladimir Lifschitz's 2001 work discussing the use of ASP for solving planning problems.
