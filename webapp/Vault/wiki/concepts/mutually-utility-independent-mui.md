# Mutually Utility Independent (MUI)

## Definition
The concept of Mutually Utility Independence (MUI) extends preference independence to situations involving uncertainty and lotteries. A set of attributes is defined as MUI if each of its subsets is utility-independent of the remaining attributes. A set of attributes X is utility independent of a set Y if preferences between lotteries on X do not depend on the particular values of the attributes in Y.

## Implication for Utility Functions
The primary significance of MUI is that it implies the agent's preferences can be described using a multiplicative utility function. This provides a structured and often simplified way to represent complex multiattribute preferences.

## Example
The text suggests that for a problem like airport siting, it is reasonable to propose that the key attributes (e.g., Noise, Deaths, Cost) are mutually utility independent.
