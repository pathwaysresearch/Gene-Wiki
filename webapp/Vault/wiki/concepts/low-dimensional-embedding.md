# Low-Dimensional Embedding

## Definition
Low-dimensional embedding is an unsupervised machine learning method that maps high-dimensional sensor streams into lower-dimensional spaces.

## Application in Robot Perception
This approach is particularly valuable in robotics when the optimal internal representation for sensor data is not known beforehand. It allows a robot to process complex sensor inputs by finding a more compact and meaningful representation, which is useful in hard perceptual problems.

## Role in Learning Models
By reducing dimensionality, this technique makes it possible to learn sensor and motion models directly from data. It enables a robot to simultaneously discover a suitable internal representation while learning how its sensors perceive the world and how its actions affect its state.
