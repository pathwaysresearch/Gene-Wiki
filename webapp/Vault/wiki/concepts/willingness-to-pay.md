# Willingness to Pay

## Definition
Willingness to pay is an economic metric representing the maximum price a consumer will pay for a product. In this study, it was used to assess the monetary value that developers placed on GitHub Copilot following their participation in the experiment.

## Measurement in the Study
An exit survey asked participants to state the highest monthly price at which they would be interested in being notified about the release of GitHub Copilot. The researchers state that the answer to this question provides an upper bound for the developers' true willingness to pay. The question was posed to both the treated group (who used Copilot) and the control group (who only viewed a tutorial).

## Key Findings
The results revealed a statistically significant difference in the perceived value of Copilot between the two groups. The treated group, having experienced the tool's benefits firsthand, reported an average willingness to pay of $27.25 per month. In contrast, the control group reported a much lower average of $16.91 per month. This difference provides indirect evidence that direct use of Copilot substantially increases its perceived value to developers.
