## Abstract

This paper presents results from a controlled experiment measuring the impact of GitHub Copilot, an AI pair programming tool, on developer productivity. Recruited software developers were asked to implement an HTTP server in JavaScript as quickly as possible, with a treatment group having access to Copilot. The study found that the treatment group completed the task significantly faster, with a revealed productivity increase of 55.8%, while participants in both groups self-estimated only a 35% productivity gain. The research contributes empirical evidence from a randomized experiment on how generative AI tools affect real coding tasks.

## Key Claims

- Developers with access to GitHub Copilot completed the coding task 55.8% faster than the control group
- Both treated and control groups self-estimated a 35% productivity increase from Copilot, underestimating the actual revealed productivity gain
- The experiment used a controlled design with a specific task (implementing an HTTP server in JavaScript) administered via GitHub Classroom
- Task completion and timing were accurately measured using repository creation timestamps and code push timestamps
- A test suite was included in the repository to validate participant submissions
