# Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow (2nd Edition, 2019)

**Type**: RAG stub — full content in vector index, not in wiki

## Abstract

This is the second edition of Aurélien Géron's comprehensive, practice-oriented textbook covering machine learning from foundational concepts through advanced deep learning, updated for TensorFlow 2. The book assumes near-zero prior ML knowledge and progresses from classical algorithms (linear regression, SVMs, decision trees) implemented in Scikit-Learn to deep neural networks, custom models, and advanced architectures built with Keras and TensorFlow. It emphasizes production-ready Python frameworks and hands-on implementation using Jupyter notebooks, making it one of the most widely used references for applied machine learning practitioners.

## Key Claims

- Machine learning can be taught effectively by using production-ready frameworks (Scikit-Learn, TensorFlow, Keras) rather than toy implementations of algorithms
- The book covers techniques ranging from the simplest and most commonly used (linear regression) to deep learning techniques that regularly win competitions
- Scikit-Learn is presented as an efficient and easy-to-use entry point for learning ML algorithms, while TensorFlow serves as a more complex library for distributed numerical computation
- Training deep neural networks requires specialized techniques for handling vanishing/exploding gradients, hyperparameter tuning, and regularization
- TensorFlow 2 enables custom model building and training workflows beyond standard Keras APIs

## Topics Covered

Linear regression, gradient descent (batch/stochastic/mini-batch), polynomial regression, regularization (Ridge/Lasso/Elastic Net), logistic regression and softmax regression, support vector machines (linear and nonlinear/kernel methods), classification (multilabel and multioutput), learning curves, neural network hyperparameter tuning, training deep neural networks, custom models and training with TensorFlow, TensorBoard visualization
