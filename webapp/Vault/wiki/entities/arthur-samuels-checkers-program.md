# Arthur Samuel's Checkers Program

## Overview
Developed by Arthur Samuel of IBM starting in 1952, this checkers program was a landmark achievement in early artificial intelligence. The text notes that Christopher Strachey wrote the first working program in 1952, but Samuel's work, beginning the same year, was particularly significant for its learning capabilities.

## Key Innovation: Learning
The program's most significant feature was its ability to learn. It improved its performance by learning its own evaluation function. This was achieved by having the program play against itself thousands of times, a technique that is described in more detail in Chapter 21 of the source text.

## Legacy
Samuel's program began as a novice but, through its learning process, quickly became a strong player. This work demonstrated the power of machine learning in a complex domain and is cited as a foundational contribution to the field. Checkers was the first of the classic games to be fully played by a computer, and Samuel's program was a key part of that history.
