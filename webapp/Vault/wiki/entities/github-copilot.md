# GitHub Copilot

## Overview
GitHub Copilot is described in the paper as an "AI pair programmer" and a generative AI tool designed to increase human productivity in software development. It functions by providing real-time code suggestions to developers within their editor.

## Role in the Experiment
In the study, GitHub Copilot was the independent variable being tested. A treatment group of software developers was given access to the tool to assist them in a timed coding task. The tool's effectiveness was measured by comparing this group's performance, particularly their task completion time, against a control group that did not have access to it. Participants in the treatment group received a tutorial and instructions on how to enable and use Copilot.

## Measured Impact and Value
The experiment found that developers using GitHub Copilot completed their assigned task 55.8% faster than those without it. Furthermore, an exit survey revealed that users who had direct experience with Copilot (the treated group) reported a willingness to pay an average of $27.25 per month for the tool. This was significantly higher than the $16.91 per month estimated by the control group, indicating that hands-on experience with the tool increases its perceived monetary value.
