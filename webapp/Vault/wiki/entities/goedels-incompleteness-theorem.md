# Gödel's Incompleteness Theorem

## Overview
Proven by Kurt Gödel, the incompleteness theorem is a landmark result in mathematical logic. It demonstrates that within any formal logical system powerful enough to describe the arithmetic of natural numbers, there are sentences that are true but cannot be proven from the system's axioms.

## Formal Context
The theorem applies to the logical theory of numbers, which is an extension of first-order logic. This language includes a constant for 0, a successor function `S` to name all natural numbers, function symbols for addition, multiplication, and exponentiation, and the standard logical apparatus. Crucially, it also includes the mathematical induction schema.

## Significance
Gödel's theorem reveals a fundamental limitation of formal axiomatic systems. It establishes that no consistent formal system that can express basic arithmetic can be complete, meaning there will always be true statements about numbers that are unprovable within that system. The proof itself is complex, often requiring over 30 pages of explanation.
