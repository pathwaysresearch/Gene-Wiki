# BERUFENET

## Overview

BERUFENET is a German expert database that provides structured information about occupations. In the context of this study, it serves as a source for occupational task measures at the 3-digit occupation level for the years 2011, 2012, and 2013.

## Task Measures

The database provides five specific task measures for occupations: analytical non-routine, interactive non-routine, cognitive routine, manual routine, and manual non-routine tasks. These measures are based on expert assessments of the work content of different jobs.

## Role in the Analysis

The researchers use the task measures from BERUFENET as a point of comparison to validate their own task measures derived from the BIBB-BAuA survey data. They find a relatively high correlation between the two sources, particularly for manual activities. This finding provides reassurance about the similarity of task structures and supports the application of O*NET-based technology exposure measures to the German labor market data.
