# Superhuman

## Overview
Superhuman is an email application that is highlighted as a great example of a modern AI-powered tool. It is discussed in the context of software that provides significant value by moving beyond traditional, rule-based functionality toward more intelligent, agent-like behavior.

## Key Feature: Auto Labels
A core feature discussed is "auto labels," which fundamentally changes how email filtering works. Instead of relying on simple rules like a sender's email address, this feature allows a user to write a human-like prompt to define a filter, such as "when I get an email that sounds like this or is about this topic then do this." This enables much more nuanced and powerful email organization based on content and intent.

## Agentic Functionality
The auto labels feature is presented as a prime example of an "agentic" system. By allowing a user to provide a small number of high-level instructions, the system can autonomously manage a complex task like sorting an entire inbox. The speaker likens this experience to hiring "20 employees to sort my email," which illustrates the power of commanding a sophisticated automated system with simple, natural language instructions.
