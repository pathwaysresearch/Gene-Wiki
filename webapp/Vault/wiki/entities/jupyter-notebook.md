# Jupyter Notebook

## Overview
Jupyter Notebook is a tool recommended in the text for walking through code examples. It operates as a server, typically running on `localhost:8888`, which can be accessed via a web browser to provide an interactive coding environment.

## Core Functionality
Creating a new notebook performs three actions: it creates a new notebook file with an `.ipynb` extension in the user's workspace, starts a Python kernel to run the code in the notebook, and opens the notebook in a new browser tab.

## Language Support
The text notes that Jupyter is not limited to a single version of Python. It can handle multiple Python versions and even supports many other languages, such as R or Octave, making it a versatile tool for data science.
