# Census Occupation Code

## Overview
The Census Occupation Code is a standardized classification system used to categorize occupations for statistical purposes. This system has evolved significantly over time, with the number of 3-digit occupation categories growing from approximately 250 in 1940 to roughly 500 in 2018. This evolution, which includes the merging, splitting, and recombining of categories, creates significant challenges for researchers attempting to construct consistent, long-term data panels.

## Data Collection Process
The code is assigned based on survey respondents' written answers on forms like the American Community Survey (ACS). As illustrated in Figure A5, respondents provide their main occupation (e.g., "4th grade teacher") and describe their most important duties (e.g., "instruct and evaluate students"). Based on these textual responses, a trained coder or an automated system assigns a standardized, multi-digit Census Occupation Code to describe the work performed.

## Role in Research
These codes are fundamental to the research presented, as they are used to create the occupation-by-industry panels that form the basis of the statistical analysis. To address the inconsistencies in the coding scheme over the eight decades from 1940 to 2018, the study's authors had to construct two separate, internally consistent panels: one for the 1940–1980 period and another for the subsequent period. This methodological choice highlights both the critical importance of the codes and the complexity of using them for longitudinal research.
