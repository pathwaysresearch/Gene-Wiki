# ASKMSR System

## Overview
The ASKMSR system, developed by Banko et al. in 2002, is a typical example of a modern, Web-based question-answering system. It was designed to leverage the vast and redundant information available on the World Wide Web to find direct answers to user questions.

## Core Principle
The system is based on the key intuition that most questions will be answered many times, in many different phrasings, across the Web. This insight reframes the question-answering task as a problem of precision (finding one of the existing correct answers) rather than recall (needing to synthesize an answer from scratch). The system only has to find one correct phrasing of an answer to succeed.

## Significance
ASKMSR represents a significant shift in the approach to question answering. By using Web information retrieval as its foundation, the system and others like it were able to radically increase their breadth of coverage compared to earlier natural language processing systems that relied on smaller, more limited knowledge bases.
