# 8-Queens Problem

## Overview
The 8-queens problem is a puzzle that requires placing eight chess queens on a standard 8x8 chessboard such that no two queens can attack each other. This means that no two queens can be on the same row, column, or diagonal. It is a common example problem used to illustrate search and constraint satisfaction algorithms.

## History
The problem was first published anonymously in the German chess magazine *Schach* in 1848 and was later attributed to Max Bezzel. It gained wider attention when the mathematician Carl Friedrich Gauss took an interest, attempting to enumerate all possible solutions. While Gauss initially found only 72, the correct number of 92 unique solutions was first published by Nauck in 1850.

## Generalization
The problem was generalized to the n-queens problem by Netto in 1901, which involves placing n queens on an n x n board. This generalized version has also been studied extensively, and an O(n) algorithm for finding a solution was developed by Abramson and Yung in 1989.
