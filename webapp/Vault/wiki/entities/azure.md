# Azure

## Initial State
Prior to 2011, Azure had been run as a separate, autonomous organization within Microsoft. This structure caused significant challenges, as the platform was disconnected from Microsoft's other product lines, often built incompatible software, and was frequently at odds with the rest of the server and tools group.

## Integration into the Core
One of Satya Nadella's first moves after taking over the Server and Tools business was to bring Azure 'into the fold.' He placed it under an experienced Microsoft executive, Bill Laing, with the mandate to move Azure from the fringe to the center of Microsoft's strategy and thereby transform the core of the company.

## Redesign and Strategic Role
As part of its integration, Azure was redesigned to be easier to use and compatible with traditional Microsoft products, making it simple to port traditional enterprise software to the new platform. In a clear departure from its early focus and to support Microsoft's new open-source direction, Azure was also redesigned to run both Windows and Linux workloads.
