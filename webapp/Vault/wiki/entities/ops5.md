# OPS5

## Overview
OPS5 is a production system language, part of a family of rule-based systems developed at Carnegie Mellon University. A user's manual for the system was published as a technical report by Charles Forgy in 1981.

## Core Technology
A key technological component of OPS5 is its use of the Rete algorithm for efficient pattern matching. This algorithm, also developed by Forgy, allows the system to quickly solve the "many patterns/many objects match problem," enabling it to determine which rules are applicable as facts in the working memory change.
