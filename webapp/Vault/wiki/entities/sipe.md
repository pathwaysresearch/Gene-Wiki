# SIPE (System for Interactive Planning and Execution monitoring)

## Overview
SIPE, which stands for System for Interactive Planning and Execution monitoring, is a practical planner developed by David E. Wilkins (1988, 1990). It is noted for its systematic approach to integrating planning with execution.

## Key Contribution: Replanning
SIPE was the first planner to deal systematically with the problem of replanning. This capability is crucial for online planning agents that must adapt to unexpected events or changes in the environment during plan execution.

## Applications
As a practical HTN planner, SIPE has been used in several demonstration projects across diverse domains. These include planning operations on the flight deck of an aircraft carrier, job-shop scheduling for an Australian beer factory, and planning the construction of multistory buildings.
